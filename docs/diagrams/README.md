# Diagrams

Editable sources are in `source/`: Graphviz `.dot` files (render with `dot -Tpng file.dot -o file.png`),
`diag.py` (regenerates all three diagrams) and `mock.py` (UI mock-up, matplotlib).

| Diagram | Export | Source |
|---|---|---|
| System context | `context.png` | `source/ctx_en.dot` |
| Use cases | `use-case.png` | `source/uc_en.dot` |
| Components (draft) | `components.png` | `source/cmp_en.dot` |
| UI mock-up (schematic) | `ui-mockup.png` | `source/mock.py` |
